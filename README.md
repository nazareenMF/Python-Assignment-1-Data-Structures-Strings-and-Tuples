# Python Assignment 1: Data Structures — Strings & Tuples

## Overview
This assignment practices basic Python operations on strings and tuples, including concatenation, indexing, slicing, string methods, tuple concatenation, repetition, and accessing tuple elements.

## Topics Covered

### 1. String Concatenation
- Combine the string `"Hello "` with a name entered by the user.
- Add `", Welcome to Python Programming"` to the resulting string.

### 2. String Indexing and Slicing
Using the concatenated string:
- Print the first character.
- Print the last character.
- Print the first five characters.
- Print the last eleven characters.
- Print the string in reverse.
- Extract the word `Python` using slicing.

### 3. String Methods
Using the string `"Python beginner tutorial"`:
- Convert the sentence to uppercase with `upper()`.
- Convert the sentence to lowercase with `lower()`.
- Use `capitalize()` and compare the result with the original string.
- Count occurrences of the character `t` with `count()`.
- Replace `Python` with `Machine Learning` using `replace()`.

### 4. Tuple Operations
Create the tuples `(10, 20, 30)` and `(40, 50, 60)`, then:
- Concatenate them and store the result in `t_combine`.
- Repeat the combined tuple three times.
- Access the third element.
- Access the first three elements.
- Access the last three elements.

## Concepts Practiced
- `+` for string and tuple concatenation
- `input()` for user input
- Positive and negative indexing
- Slicing with `[start:end:step]`
- String methods: `upper()`, `lower()`, `capitalize()`, `count()`, and `replace()`
- `*` for tuple repetition
- Tuple immutability
